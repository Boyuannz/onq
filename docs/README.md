# OnQ project page

Source of https://boyuannz.github.io/onq/, served by GitHub Pages from `main` `/docs`.

- `index.html`: page text and layout.
- `static/js/data.js`: numbers behind the tables and charts, taken from the paper.
- `static/js/site.js`: draws the charts and tables from `data.js`.
- `static/images/method_overview.svg`: the method diagram from the paper.

Figure 1 and the trace excerpts use the seed-42 Qwen3-1.7B W2 MATH-500 outputs for "How many zeroes are at the end of 42!?"; token positions were counted with the Qwen3 tokenizer.
